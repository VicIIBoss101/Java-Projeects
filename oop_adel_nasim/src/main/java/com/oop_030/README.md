انا نظمت كل باكيج يمثل درس معين و داخل نفس الباكيج راح اضيف باكيجيز ثانية للترتيب 
--
طبعا اكيد داخل كل باكيج راح يكون كلاسات الي تخص الدرس 

--
ملاحظات من المحاضرة:
- الكلاسات تبدا بحرف كبير.
- الكلاس الي ننشاه يجب ان يكون داخل نفس الباكج و اذا من باكيج ثاني نستدعي الباكيج (استنتاج من عندي)
- أنشاء الكلاسات يكون في الـ main كلاس 
o نكتب اسم الكلاس بعدها اسم الاوبجيكت الي نريده
o بعدها نعيين هذا الاوبجيكت شنو يستقبل مثلا:
o Car myObj;
o myObj = new Car();
o بهذا الشكل نكون انشئنا كائن من كلاس الكار
- عند انشاء كائن مثلا كائن1 و ملئ المتغيرات عن انشاء كائن ثاني فان الكائن الثاني يختلف عن الاول بكل شي من ناحية القيم يعني اذا اطيت الاوبجيكت الاول في متغير الاسم شيء فانه يختلف عن الثاني يعني ماكو تداخل بين الاثنين بس له نفس الخواص ( اسم , سعر , سرعة )على سبيل المثال.
- ملاحظة عامة اي متغير من نوع string  اذا ما اعطيناه قيمه و ااجينا نطبعه يعطي بالطباعة null
